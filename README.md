What is this project?
This is a flask webApp that was made for the fire department of the Brabant Wallon (ZSBW) to create fire prevention repports for temporary installations
Why is it public?
Only the code files are public, and internal files will not be released, so there is no risks of making this open source
How do I use it?
First, make sure python is installed on your device and run pip install /installScripts/requirements.txt
Secondly, configure your .env file by taking example on the .env.example
Then, configure the word file and the rapport.html page based on your word file
You should also create the database inside /database, and name it credentials.db
Finaly, the program is ready to run. Run main.py and connect to localhost on port 5000 (http://localhost:5000)
