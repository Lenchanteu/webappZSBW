Demande de transmission des données collectées

Conformément au RGPD, vous pouvez demander l'accès à vos données personnelles, leur rectification, leur suppression ou leur export. Vous pouvez effectuer ces demandes à partir de cette page.

En cliquant sur le bouton ci-dessous, un fichier contenant les données personnelles associées à votre compte sera généré et téléchargé. Ce fichier comprend uniquement les informations enregistrées pour le fonctionnement de votre compte.

Données incluses :

  • 1. Nom d'utilisateur
  • 2. Adresse e-mail
  • 3. État de confirmation de l'adresse e-mail
  • 4. Dernière adresse IP de connexion

Pour des raisons de sécurité, votre mot de passe haché (Argon2id) ainsi que les informations techniques associées à son stockage ne sont pas inclus dans l'export.

Pour protéger vos données personnelles, une authentification est nécessaire avant de pouvoir télécharger les informations associées à votre compte.

En remplissant le formulaire ci-dessous, vous pouvez supprimés des données non-essentielles de votre compte. Si vous voulez supprimer toutes les données collectés vous concernant, veuillez procéder à une suppression de votre compte ici: Suppression du compte.

Données non essentielles :

    1. Dernière adresse IP de connexion
